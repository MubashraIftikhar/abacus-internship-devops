# 🚀 DevOps Documentation

This repository documents my hands-on learning journey during my internship at **Abacus**, covering core DevOps tools and practices — from containerization to CI/CD, orchestration, logging, and monitoring. Each section includes real hands-on tasks I implemented and step-by-step walkthroughs.

## 📚 What's Inside

| # | Tool | What It Covers |
|---|---|---|
| 01 | [Docker](./01-docker) | Containerization fundamentals, Dockerfile, images, networking, volumes, image optimization, and a 3-tier Docker Compose project |
| 02 | [Jenkins](./02-jenkins) | CI/CD concepts, pipelines (declarative/scripted/parametrized), secrets, shared libraries, and 3 hands-on automation tasks |
| 03 | [Kubernetes](./03-kubernetes) | Orchestration concepts, architecture, probes, pod lifecycle, workloads, services, ConfigMaps/Secrets, and a full 3-tier app migration from Compose to K8s |
| 04 | [ELK Stack (Logging)](./04-elk-stack-logging) | Centralized logging with Elasticsearch, Logstash, and Kibana |
| 05 | [Monitoring (Prometheus & Grafana)](./05-monitoring-prometheus-grafana) | Metrics collection, scraping, dashboards, and alerting |
| 06 | [Git & GitHub](./06-git-github) | Version control workflows, branching strategies, and collaboration practices |
